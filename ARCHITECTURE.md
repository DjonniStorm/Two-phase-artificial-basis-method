## 🔍 Парсинг уравнений

### parseEquation()

**Пример:** `"x1 + x2 <= 8"`

```
Шаг 1: Удаление пробелов
  "x1+x2<=8"

Шаг 2: Поиск оператора
  Регулярка: /(.+?)(<=|>=|[<>=])(.+)/
  Результат:
    lhs = "x1+x2"
    operator = "<="
    rhs = "8"

Шаг 3: Парсинг коэффициентов
  Для каждой переменной (x1, x2):
    Регулярка: /([+-]?)(\d*\.?\d*)x1/g
    Находит: "x1" → коэффициент = 1
    Находит: "x2" → коэффициент = 1

Результат:
  {
    coefficients: [1, 1],
    rhs: 8,
    type: "<="
  }
```

### parseObjective()

**Пример:** `"z=3x1 + 2x2"`

```
Шаг 1: Удаление "z="
  "3x1+2x2"

Шаг 2: Парсинг коэффициентов
  Для x1: находит "3x1" → 3
  Для x2: находит "2x2" → 2

Результат: [3, 2]
```

## 🎯 Двухэтапный симплекс-метод

### Зачем нужен двухэтапный метод?

Когда система ограничений содержит:

- Неравенства `>=` (требуют surplus переменные)
- Равенства `=` (требуют искусственные переменные)

Нет очевидного начального базисного решения → нужен **искусственный базис**.

### Этап 1: Поиск допустимого решения

```
Цель: Минимизировать сумму искусственных переменных

Исходная система:
  x1 + x2 <= 8
  2x1 + x2 >= 6
  x1 + 2x2 = 10

После преобразования:
  x1 + x2 + s1 = 8          (slack переменная)
  2x1 + x2 - e1 + a1 = 6    (surplus + искусственная)
  x1 + 2x2 + a2 = 10        (искусственная)

Целевая функция этапа 1:
  min: a1 + a2  (минимизировать сумму искусственных)
```

**Алгоритм этапа 1:**

```
1. Создать начальную таблицу с искусственными переменными в базисе
2. Обнулить коэффициенты искусственных переменных в целевой функции
3. Выполнить симплекс-метод для минимизации суммы искусственных
4. Проверить: все искусственные переменные = 0?
   ├─ Да → перейти к этапу 2
   └─ Нет → задача не имеет допустимого решения
```

### Этап 2: Оптимизация исходной целевой функции

```
Цель: Оптимизировать исходную целевую функцию

1. Удалить искусственные переменные из таблицы
2. Использовать базис, найденный на этапе 1
3. Установить исходную целевую функцию
4. Выполнить симплекс-метод для оптимизации
```

### Визуализация процесса:


## 🔄 Симплекс-метод

### Основная идея

Симплекс-метод - это итеративный алгоритм, который:

1. Начинает с некоторого базисного допустимого решения
2. На каждой итерации улучшает решение
3. Останавливается, когда достигнуто оптимальное решение

### Структура симплекс-таблицы

```
┌──────┬──────┬──────┬──────┬──────┬──────┐
│ Базис│  x1  │  x2  │  s1  │  e1  │  RHS │
├──────┼──────┼──────┼──────┼──────┼──────┤
│  s1  │  1   │  1   │  1   │  0   │  8   │
│  x1  │  1   │  0   │ -1   │  1   │  2   │
├──────┼──────┼──────┼──────┼──────┼──────┤
│  min │ -3   │ -2   │  0   │  0   │      │
└──────┴──────┴──────┴──────┴──────┴──────┘
```

### Алгоритм симплекс-метода

```
1. Проверка оптимальности
   ├─ Для минимизации: есть ли отрицательные коэффициенты в целевой функции?
   │  └─ Да → не оптимально, выбрать входящую переменную
   └─ Для максимизации: есть ли положительные коэффициенты?
      └─ Да → не оптимально, выбрать входящую переменную

2. Выбор входящей переменной (entering variable)
   ├─ Для минимизации: переменная с наименьшим (наиболее отрицательным) коэффициентом
   └─ Для максимизации: переменная с наибольшим (наиболее положительным) коэффициентом

3. Выбор выходящей переменной (leaving variable)
   └─ Правило минимального отношения:
      ratio = RHS / коэффициент_в_строке
      Выбрать строку с минимальным положительным ratio

4. Pivot операция (поворот)
   └─ Преобразование таблицы для нового базиса

5. Повторять шаги 1-4 до достижения оптимальности
```

### Pivot операция (детально)

**Цель:** Преобразовать таблицу так, чтобы входящая переменная стала базисной.

**Шаги:**

```
1. Нормализация ведущей строки
   ┌─────────────────────────────┐
   │ Все элементы строки / pivot │
   │ элемент                     │
   └─────────────────────────────┘

2. Обновление остальных строк
   ┌──────────────────────────────────────────────┐
   │ Для каждой строки i (кроме ведущей):         │
   │   factor = строка[i][входящая_колонка]       │
   │   строка[i] = строка[i] - factor * ведущая   │
   └──────────────────────────────────────────────┘

3. Обновление целевой функции
   ┌──────────────────────────────────────────────┐
   │ factor = objective[входящая_колонка]        │
   │ objective = objective - factor * ведущая    │
   └──────────────────────────────────────────────┘
```

**Пример pivot операции:**

```
До pivot (входящая: x1, выходящая: s1):
┌──────┬──────┬──────┬──────┬──────┐
│ Базис│  x1  │  x2  │  s1  │  RHS │
├──────┼──────┼──────┼──────┼──────┤
│  s1  │  1   │  1   │  1   │  8   │ ← ведущая строка
│  x2  │  0   │  1   │  0   │  2   │
├──────┼──────┼──────┼──────┼──────┤
│  min │ -3   │ -2   │  0   │      │
└──────┴──────┴──────┴──────┴──────┘

Шаг 1: Нормализация (делим на 1):
  s1: [1, 1, 1, 8] → [1, 1, 1, 8]

Шаг 2: Обновление строки x2:
  factor = 0
  x2: [0, 1, 0, 2] - 0 * [1, 1, 1, 8] = [0, 1, 0, 2]

Шаг 3: Обновление целевой функции:
  factor = -3
  min: [-3, -2, 0] - (-3) * [1, 1, 1] = [0, 1, 3]

После pivot:
┌──────┬──────┬──────┬──────┬──────┐
│ Базис│  x1  │  x2  │  s1  │  RHS │
├──────┼──────┼──────┼──────┼──────┤
│  x1  │  1   │  1   │  1   │  8   │ ← теперь x1 в базисе
│  x2  │  0   │  1   │  0   │  2   │
├──────┼──────┼──────┼──────┼──────┤
│  min │  0   │  1   │  3   │      │
└──────┴──────┴──────┴──────┴──────┘
```

## 📊 Расчет погрешностей

### Исходные данные

**Погрешность входных данных:**

```
Погрешность = половина последнего знака

Примеры:
  48    → 0.5
  48.01 → 0.005
  48.123 → 0.0005
```

### Формулы распространения погрешностей

**1. Погрешность суммы:**

```
ΔS = Δx₁ + Δx₂ + ... + Δxₙ

Пример:
  x = 10.5 ± 0.05
  y = 20.3 ± 0.05
  S = x + y = 30.8
  ΔS = 0.05 + 0.05 = 0.1
```

**2. Погрешность произведения:**

```
ΔP = |P| · (Δx₁/|x₁| + Δx₂/|x₂|)

Пример:
  x = 10 ± 0.5
  y = 20 ± 1.0
  P = x · y = 200
  ΔP = 200 · (0.5/10 + 1.0/20) = 200 · 0.1 = 20
```

**3. Погрешность частного:**

```
ΔQ = |Q| · (Δx/|x| + Δy/|y|)

Пример:
  x = 100 ± 1
  y = 10 ± 0.1
  Q = x/y = 10
  ΔQ = 10 · (1/100 + 0.1/10) = 10 · 0.02 = 0.2
```

### Расчет погрешностей результатов

**Упрощенная модель:**

```
1. Вычисляем среднюю погрешность входных данных
   avgUncertainty = среднее(все погрешности входных)

2. Для каждой переменной результата:
   criticalOps = умножения + деления
   accumulationFactor = 1 + sqrt(criticalOps) * 0.1
   resultUncertainty = avgUncertainty * accumulationFactor

3. Для оптимального значения:
   Для каждого слагаемого в целевой функции:
     productUncertainty = погрешность(коэффициент * переменная)
     optimalUncertainty += productUncertainty
```

**Пример:**

```
Входные данные:
  Коэффициенты: 3.0 ± 0.05, 2.0 ± 0.05
  RHS: 8.0 ± 0.05

Операции: 50 умножений, 30 делений

Средняя погрешность входных: 0.05
criticalOps = 80
accumulationFactor = 1 + sqrt(80) * 0.1 ≈ 1.9

Погрешность x1: 0.05 * 1.9 ≈ 0.095
Погрешность x2: 0.05 * 1.9 ≈ 0.095

Погрешность z = 3x1 + 2x2:
  Δ(3x1) = |3| * (0.05/3 + 0.095/6) ≈ 0.3
  Δ(2x2) = |2| * (0.05/2 + 0.095/2) ≈ 0.15
  Δz = 0.3 + 0.15 = 0.45
```
